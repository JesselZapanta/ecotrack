## Summary

Implemented JWT authentication end-to-end. `POST /api/auth/login` accepts email or username, returns a bearer token (60 min), the user resource, and the role dashboard path. `me` restores sessions, `logout` blacklists the token, and `refresh` rotates it. Seeded 4 offices and 5 users. The React app now stores the token, attaches it via axios, guards routes, redirects each role to its own dashboard, and logs out cleanly.

Verified:
- `php artisan test` → **13 passed (44 assertions)** including 11 auth tests.
- Live API: admin → `/admin/dashboard`, ben → `/maintenance/dashboard`, educ → `/office/dashboard`; `me` works; logout returns 401 afterwards.
- CORS preflight from `http://localhost:5173` returns 204 with allow-origin.
- `npm run build` and `npm run lint` pass.
