## Summary
Offices is now fully server-driven with the same UX as Users/Categories: debounced server search (name/contact), sortable Office column, server-side pagination with meta footer, skeleton rows + loading bar + search spinner on every fetch, create/edit dialog, delete behind `ConfirmDialog`. Deleting an office is safe — `users.office_id` is `nullOnDelete`. The users-module office select was updated to fetch `per_page=100` since the endpoint is now paginated.

Verified: `php artisan test` → **47 passed (185 assertions)** including 9 new office tests; live API CRUD round trip (create → search → delete); `npm run build` ✓ and `npm run lint` clean; browser screenshots at 1440px confirm loaded table and add dialog.
