## Summary
The PDF endpoint embedded `brand/tcgc-logo.png` directly. That seal has a transparent background, and dompdf's CPDF adapter needs the GD extension to embed transparent PNGs. On a machine without GD, `addPngFromFile()` throws `The PHP GD extension is required, but is not installed.`, which surfaces as a 500 on the download/print endpoint while the rest of the app works.

The report header now uses a flattened JPEG seal, which dompdf embeds natively without GD. The PNG remains as a guarded fallback when GD is present. The dompdf font-cache directory is now tracked, and the frontend surfaces the real error message when a PDF request fails.
